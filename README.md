# Until Dawn

Until Dawn is a single-player survival horror game about a night security guard trying to survive from 12 AM to 6 AM while avoiding three ghosts. This repository currently contains only the JavaFX application entry point and a structure for future OOP coursework.

## Tech stack

- Java 21
- JavaFX 21
- Maven
- JavaFX CSS and JSON (planned for future development)

## Requirements

- JDK 21
- Maven 3.9 or later

## Build and run

From the project root, build with:

```sh
mvn clean package
```

Run the application with:

```sh
mvn clean javafx:run
```

The application opens a 1280 × 720 black window with **UNTIL DAWN** centered on screen.
